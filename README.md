# ヘクサ・クロニクル (Hexa Chronicle)

ブラウザで動く 3D のターン制 4X ストラテジーゲームです。Three.js で描画し、Cloudflare Workers（静的アセット配信 + KV）で動かします。
文明・指導者・都市名は本作オリジナルです。3D は大半をコードで生成し、中世までの建物と樹木・岩の一部に CC0 のモデルパックを使っています（[ASSETS.md](ASSETS.md)）。

## 遊べる内容

- 六角マップの自動生成（大陸・気候・丘陵・山岳・森林・川・資源、シード値で再現可能）
- 川：タイルの辺に沿って流れ、川沿いはゴールド+1・農場の食料+1。渡河は移動力をすべて消費し、近接攻撃は戦闘力-5（「建築学」で橋が架かり移動の制約は解消）
- 8 文明（それぞれ固有の特性）、AI 対戦（最大 7 文明）、蛮族と野営地
- 都市（人口成長・市民の自動配置・国境拡大・建造物 18 種・ゴールドでの購入・生産キュー）
- 自然遺産 6 種（発見ボーナスと固有の産出）、海沿いの崖
- ユニット 22 種（近接・対騎兵・遠隔・騎兵・攻城・海軍・開拓者・労働者・斥候）、乗船、遠隔攻撃、都市の占領
- 技術ツリー 36 種（太古 → 宇宙）、地形改良 5 種、戦場の霧、外交（宣戦・和平）
- 勝利条件：制覇（全文明の最初の首都を支配）／科学（恒星間探査船）／スコア（300 ターン）
- セーブ：ブラウザ（オートセーブあり）とクラウド（Workers KV）

## 開発

```bash
npm install
npm run dev        # Vite 開発サーバー（http://localhost:5173）
npm run sim        # AI 同士の自動対戦でルールを検証（例: npm run sim -- 3 large 300）
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド済みを wrangler dev で確認（クラウドセーブ API 込み、http://localhost:8787）
```

`npm run dev` 中にクラウドセーブも試す場合は、別ターミナルで `npx wrangler dev` を起動してください（`/api` は 8787 番へプロキシされます）。

## Cloudflare へのデプロイ

```bash
npx wrangler login   # 初回のみ
npm run deploy       # ビルドして wrangler deploy
```

- `wrangler.jsonc` の KV バインディング `SAVES` は ID を省略しているため、初回デプロイ時に Wrangler が自動で作成します。
- バインディングを変更したら `npx wrangler types worker/worker-configuration.d.ts` で型を再生成してください。
- GitHub と連携する場合は、Cloudflare ダッシュボードの Workers Builds でこのリポジトリを接続し、ビルドコマンドに `npm run build`、デプロイコマンドに `npx wrangler deploy` を指定します。

## 構成

```
src/core/     ゲームルール（DOM・描画に依存しない純粋な TypeScript）
  types.ts    状態とアクションの型（状態はすべて JSON 化可能）
  data.ts     文明・ユニット・建造物・技術などのデータ
  hex.ts      六角座標、乱数、ノイズ
  mapgen.ts   マップ生成
  game.ts     ルール本体。applyAction(state, playerId, action) が唯一の入口
  ai.ts       AI と蛮族（人間と同じ applyAction だけで行動する）
src/render/   Three.js による描画
  terrain.ts  高さ場と地形メッシュ、水面
  shaders.ts  グリッド・国境・ハイライト・戦場の霧をシェーダー内で描画
  props.ts    山・木・資源・地形改良（InstancedMesh）
  districts.ts 区域の配置計画
  fx.ts       粒子エフェクト
  pack.ts     外部モデルパックの読み込み
  post.ts     後処理（AO・ティルトシフト・色調）
  models.ts   ユニットと都市のプロシージャルモデル
  view.ts     カメラ、ピッキング、アニメーション、ラベル
src/ui/       HUD とモーダル（素の DOM）
src/main.ts   状態・描画・UI をつなぐコントローラー
worker/       Cloudflare Worker（クラウドセーブ API）
scripts/sim.ts  ヘッドレス自動対戦
scripts/build-assets.ts  外部モデルパックの変換
```

### 見た目の方針

- 未探索の領域は古地図（羊皮紙）として描き、探索済みで視界外の領域はセピア調に落とします
- 山は面のはっきりした岩山メッシュ（気候で雪山・岩山・赤い岩山を出し分け）、森は広葉樹・針葉樹・ヤシ・密林樹を混在
- 地表は頂点カラーに加えて、質感ごとの模様（草目・風紋・雪のきらめき・岩の地層）と疑似的な凹凸、流れる雲の影をシェーダーで生成（画像テクスチャは不使用。画質「低」では省略）
- 建物は壁の窓・屋根の瓦の段・石畳の目地をシェーダーで描画
- 画質「中」「高」では後処理を実行：深度から計算する環境光の遮蔽（AO）、近景での上下ぼかし（ティルトシフト）、色調補正
- 国境は文明の 2 色（主色の帯 + 副色の細線）、都市は石畳の台地の上に時代ごとの建物を配置
- 川は高さ場に溝を掘って水面を見せる方式（追加のメッシュなし）
- 建造物に応じて、学術・商業・工業・文化の区域と港が都市の隣のタイルに建つ（見た目のみで、タイルの産出や改良には影響しない）
- 戦闘は矢の斉射・砲弾・火花・土煙、都市の建設と占領は紙吹雪、工場と野営地からは煙（粒子は 1 ドローコール）
- UI の書体はゴシック体で統一

### 軽さのための工夫

- 地形は 1 メッシュ、木や資源は種類ごとに 1 ドローコール（InstancedMesh）
- グリッド線・国境・移動範囲・戦場の霧はジオメトリを増やさず、マップ幅×高さの小さなデータテクスチャを参照してシェーダーで描画
- 画質は 低 / 中 / 高 の 3 段階（地形の分割数・影・解像度・質感の模様・後処理）。タッチ端末は初期値が「低」
- トーンマッピングと sRGB 変換は各シェーダー内で行い、レンダラー側の変換は使わない（画面へ直接描く場合も後処理を通す場合も同じ色になる）
- 本番ビルドは JS 約 720KB（gzip 約 200KB）+ モデルパック約 600KB（gzip 約 230KB）。画像テクスチャのダウンロードはなし

### オンライン対戦への拡張

ルールは `applyAction` に集約され、乱数も状態内（`state.rng`）に持つ決定論的な実装です。
そのため、対戦部屋ごとの Durable Object に `GameState` を持たせ、クライアントからは `Action` を WebSocket で送り、
サーバー側で `applyAction` → 各プレイヤーへ（視界でフィルタした）結果を配信する、という形で拡張できます。
現状はクライアント内で全プレイヤーの状態を持つシングルプレイ専用です。

## 既知の制限

- 3D はローポリのスタイライズド表現です。質感の模様は計算で作っており、描き込まれた画像テクスチャ・指導者の演出はまだありません。ユニットの関節の動きは歩行・攻撃・構えのみです。
- 道路・交易路・宗教・社会制度・都市国家・昇進（経験値）・ユニットのアップグレードは未実装です。
- 視界の遮蔽（山による視線ブロック）と支配領域（ZOC）は未実装です。
- クラウドセーブは「引き継ぎコードを知っていること」だけで読み書きできる簡易方式です。公開運用する場合は認証とレート制限を追加してください。
